# 탐구 문제풀이

수능 탐구과목 문제를 랜덤으로 출제하고, 즉시 채점하며, 취약 영역을 분석하는 웹 프로그램입니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 프로그램 본체 |
| `questions.xlsx` | **공용 문제은행**. 접속자 모두에게 자동 배포됨 |
| `images/` | 문제 이미지 폴더. `questions.xlsx`의 '이미지' 열에 파일명 기입 |

## 문제 업데이트 방법
### 방법 1. 웹 화면에서 바로 게시 (권장)
1. 사이트 → **문제관리 → 🔐 관리자 설정** 에서 GitHub 토큰 연결 (최초 1회)
   - 토큰: GitHub → Settings → Developer settings → Fine-grained tokens → 이 저장소만 선택, **Contents: Read and write**
2. 문제 파일 업로드 → 저장 위치 **'🌐 공용 문제은행에 게시'** → 게시
3. 약 1~2분 후 모든 사용자에게 자동 반영 (접속·새로고침·탭 복귀 시)

### 방법 2. 저장소에서 직접 교체
`questions.xlsx`를 수정해 저장소에 업로드 → Commit

> 문항ID는 반드시 고유하게 유지하세요 — 학습기록이 문항ID로 연결됩니다.
> 토큰은 관리자 브라우저에만 저장되며, 절대 저장소 파일에 넣지 마세요.

## 유의사항
- 학습기록은 사용자 각자의 브라우저에 저장됩니다. (서버에 저장되지 않음)
- 저장소와 `questions.xlsx`는 공개되므로 저작권 있는 문항 게시에 유의하세요.
