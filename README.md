# 탐구 문제풀이

학년별·과목별 문제은행으로 문제를 출제하고, 즉시 채점하며, 사용자별 학습기록과 취약 영역을 분석하는 웹 프로그램입니다.

## 구성
| 구성 | 위치 | 내용 |
|---|---|---|
| 화면 | `index.html` (GitHub Pages) | 프로그램 본체 |
| 데이터 | Supabase DB | 회원·학년, 문제은행(학년×과목)·문항, 풀이기록·오답노트, 문제 이미지 |
| DB 구조 | `supabase_schema_v2.sql` | 테이블·권한(RLS)·함수 정의 (v1 이후 실행) |

## 사용
- **사용자**: 로그인 → 학년 선택(최초 1회, [내 정보]에서 변경) → 해당 학년의 과목별 문제은행으로 풀이
- **관리자**: [문제관리] 학년 선택 → 과목별 문제 파일 업로드(추가 / 과목만 교체) · [사용자] 사용자 추가·권한·학년·비밀번호, 사용자별 분석·풀이기록 조회

## 규칙
- 문항ID는 **전체 학년에서 고유**해야 합니다 (학년 접두어 권장: `H3-EAR-001`). 풀이기록은 문항ID로 연결됩니다.
- `bank.enc`, `users.json`은 이전 버전 데이터입니다. 관리자가 [기존 문제은행 이전]을 마친 뒤 삭제해도 됩니다.
